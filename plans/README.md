## Findings considered and rejected

- **SEC-01** (S2 PDF cache key collision): on re-read the keying is
  correct — the URL is included in the cache hash. Not a real bug.
- **SEC-04** (SSRF IPv6 ULA gap): defense-in-depth only; public DNS
  won't resolve to ULA. The test gap (030 step 4) covers the real risk.
- **DEBT-02** (Rust/TS SSE duplication): fully de-duplicating requires
  WASM or a shared schema — too high risk for the value. The parity
  tests in 027 step 3 are the right mitigation.
- **DES-10** (resize separator keyboard): valid finding but MED effort
  and MED confidence; deferred until the other a11y fixes (028 step 4)
  land, then it can be a follow-up.
- **DES-15** (streaming cursor size inconsistency): too minor to plan
  separately; fix during the next reader touch.
