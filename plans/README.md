## Findings considered and rejected

- **Per-card `Intl.DateTimeFormat` memoization** (perf): not worth doing —
  ≤20 cards, native Intl is already fast; the formatter is created per
  render and the cost is negligible.
- **List virtualization at 20 items** (perf): not worth doing — the paper
  list is capped at 20-50 entries by design.
- **Bundle splitting / font optimization** (perf): not worth doing — the
  app is a local desktop bundle (~400 KB JS, fonts embedded); no network
  delivery cost.
- **`tailwindcss` in `dependencies` vs `devDependencies`** (deps): no
  effect — everything is bundled by Tauri; moving it adds churn for zero
  benefit.
- **Full CSP with static `connect-src` whitelist** (security): impractical
  — users configure arbitrary provider base URLs; a strict `connect-src`
  cannot express that. Adopted as documentation (023) + capability trim
  (007) instead. If HTML rendering (markdown) is ever added, revisit.
- **Stronghold plugin for keys** (deps): rejected in favor of vendoring
  the `keyring` crate (024) — stronghold needs a master-password UX that
  contradicts the app's simplicity goal.
- **The "stream ended unexpectedly" error on clean close** was folded into
  plan 001 (EOF without `[DONE]` + received content → success), not a
  separate finding.
