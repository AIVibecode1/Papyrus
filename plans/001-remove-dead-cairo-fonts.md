## Why this matters

The design pass in commit `692c0d0` replaced the Cairo font with bundled
Geist Sans / Geist Mono / IBM Plex Sans Arabic / Instrument Serif. The
font-family stack in `src/index.css` no longer references Cairo, but
`src/main.tsx` still imports four `@fontsource/cairo` weights. Result:
24 Cairo woff/woff2 files (latin + latin-ext + arabic, 4 weights, roughly
600 KB) ship in the production bundle (`dist/assets/cairo-*.woff2`) and are
never used. Removing the imports drops the dead payload, removes the
`@fontsource/cairo` dependency, and removes a confusing contradiction
between the CSS design system and the JS entry point.

Repo convention: the font stack is the single source of truth for type;
entry-point imports must not contradict it. See `src/index.css` `@font-face`
block for how the current fonts are declared.

## Steps

### Step 1: Remove the imports

Edit `src/main.tsx` and delete the four `@fontsource/cairo/...` lines
(current lines 3-6). Do not touch anything else in the file.

**Verify**: `grep -rn "fontsource/cairo" src/` → no matches.

### Step 2: Remove the dependency

Run `pnpm remove @fontsource/cairo` from the repo root (project-local only;
this modifies `package.json` and `pnpm-lock.yaml`).

**Verify**: `grep -n "fontsource/cairo" package.json pnpm-lock.yaml` → no
matches.

### Step 3: Prove the payload is gone

Rebuild the production bundle and confirm no Cairo files survive.

**Verify**:

1. `pnpm exec vite build` → "✓ built in" and exit 0
2. `ls dist/assets/ | grep -i cairo` → no output (empty)
