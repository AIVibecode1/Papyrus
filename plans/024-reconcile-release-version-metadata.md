## Why this matters

The release metadata is inconsistent: the frontend package and Tauri configuration report `1.0.4`, while the Rust manifest and Cargo lock package entry report `1.0.2`. This weakens reproducibility and can produce installers whose displayed metadata does not match the Rust package provenance.

## Current state

- `package.json:4` reports version `1.0.4`.
- `src-tauri/tauri.conf.json:4` reports version `1.0.4`.
- `src-tauri/Cargo.toml:3` reports version `1.0.2`.
- `src-tauri/Cargo.lock:2618-2619` records the Papyrus package as `1.0.2`.
- `release.md:22-27` describes v1.0.4 but its build provenance must be verified against the final release commit.
- AGENTS.md requires all three manifests to be bumped together and installers rebuilt.
